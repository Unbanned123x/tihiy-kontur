# Сервер комнат «Тихого контура»

Node.js без зависимостей. Один процесс, комнаты в памяти, до 4 игроков на комнату.
Развёрнут на Render Free: https://<ваш-сервис>.onrender.com

## Запуск локально

```
node server/index.js
```

Проверка: http://127.0.0.1:8080/health → {"ok":true,...}

## Деплой на Render

1. Залейте репозиторий на GitHub (папка `server/` внутри).
2. Render → New → Blueprint → выберите репозиторий. Файл `render.yaml` подхватится сам.
   Либо вручную: New → Web Service → Root Directory: `server` → Build: `npm install` →
   Start: `node index.js` → Plan: Free.
3. Через минуту сервис даст адрес `https://<name>.onrender.com`.
4. Проверьте `/health`. Для клиента адрес WebSocket: `wss://<name>.onrender.com`.

## Поведение бесплатного тарифа

- Засыпает после 15 минут **без трафика**, но сообщения по открытому WebSocket считаются
  трафиком, поэтому активная комната держит сервис живым.
- Холодный старт после сна: около минуты. Первый игрок может ждать.
- Память не сохраняется: комнаты живут в RAM, после перезапуска всё обнуляется.
  Это нормально для сессионного коопа.

## Протокол

Клиент → сервер:

| Сообщение | Поля | Смысл |
|---|---|---|
| `join` | room, name | войти в комнату (до 4 человек) |
| `state` | x, y, a, wave, hp, dead | позиция и состояние, 15–20 раз в секунду |
| `event` | kind, x, y | выстрел, удар, смерть |
| `ping` | — | проверка связи |

Сервер → клиент:

| Сообщение | Поля | Смысл |
|---|---|---|
| `joined` | id, room, host | подтверждение входа |
| `peers` | list | кто уже в комнате |
| `peer` | id, name | кто-то подключился |
| `leave` | id | кто-то вышел |
| `state` | id, x, y, a, w, hp, dead | состояние другого игрока |
| `event` | id, kind, x, y | событие другого игрока |
| `host` | — | вы стали хостом |
| `full` | — | комната заполнена |
| `pong` | — | ответ на ping |

## Архитектура (следующий шаг)

Хост-авторитет: мир считает один игрок (host), остальные отправляют только ввод,
хост рассылает состояние зомби и волн. Сервер — ретранслятор, без игровой логики.
Это в разы дешевле выделенного сервера и достаточно для 4 игроков.
