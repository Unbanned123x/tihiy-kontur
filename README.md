# Тихий контур — сайт

Статический лендинг игры. Публикуется через GitHub Pages.

## Публикация

1. Создайте репозиторий на github.com (например, `tihiy-kontur`).
2. Загрузите **содержимое этой папки** в корень репозитория
   (Add file → Upload files → перетащите все файлы, кроме README.md при желании).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`.
4. Через 1–2 минуты сайт будет доступен:
   `https://<ваш-ник>.github.io/tihiy-kontur/`

## Что важно

- Все пути относительные, поэтому сайт работает в подпапке репозитория.
- `.nojekyll` нужен, чтобы GitHub не прогонял файлы через Jekyll.
- Скачивание ведёт на `tihiy-kontur-3.9.7.apk` в этой же папке.
- Если APK не проходит по лимиту, загрузите его в **Releases** и поменяйте
  ссылку `href` в `index.html` на адрес релиза.
